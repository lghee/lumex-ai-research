# LUMEX AI 트레이더 포워드 관측용 850개 확정봉 확대

- 수정 대상: Worker 기존 `GET /market-hub/v1/candles` 인증된, 읽기 전용 조회.
- 기본 호출은 이전과 같은 최대 500봉. **명시적 `limit=850`** 에만 최대 850봉 허용.
- `limit=500`, `limit=850` 외의 요청은 400 오류. 회원의 주문 권한은 변경하지 않음.
- R2 `market/<BTC|ETH|SOL|XRP>USDT_60.csv` 원본 검증, 60/240분 4종목만 사용.
- WordPress Core 0.6.34는 Cloudflare 검증된 확정봉·통일된 타임스탬프·최소 230봉(4H)/673봉(1H)·최신성 확인 후 7전략 10k 가상 포워드만 실행.
- 충분한 봉이 없거나 5분 주기 Cron/R2가 정지하면 **가상 체결 없음**. 빈 백테스트를 복제하거나 시드 수익률만 곱하지 않음.
- 병합 후에도 Cloudflare 수동 배포가 필요. 실제 시세가 850봉을 반환할지는 운영 R2 보유 구간에 달려 있음.
- WordPress 공유 호스팅에는 이미 검증된 Worker R2 데이터만 받으며 외부 거래소를 직접 스캔하지 않도록 우선 경로를 전환.
- 원본 연구 전략과 실행 동일성 미입증 상태이며 실제 주문과 무관.
